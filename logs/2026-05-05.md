# 📈 Moving Average (이동평균) 정리

## 1. 정의

이동평균(MA)은 최근 N일 가격의 평균으로,
가격의 추세(Trend)를 파악하기 위한 지표이다.

$$MA_t = \frac{1}{N} \sum P_{t-i}$$

---

## 2. 계산 방법

```python
df['ma20'] = df['Close'].rolling(20).mean()
```

* rolling(20): 최근 20일 데이터 묶기
* mean(): 평균 계산

---

## 3. 사용 목적

* 가격 노이즈 제거
* 추세 파악

---

## 4. 주요 기간

| 기간   | 의미  |
| ---- | --- |
| 5일   | 단기  |
| 20일  | 1개월 |
| 60일  | 중기  |
| 200일 | 장기  |

---

## 5. 핵심 파생 변수

### (1) 가격 대비 이동평균

```python
df['price_ma20_ratio'] = df['Close'] / df['ma20']
```

* > 1 → 상승 압력
* < 1 → 하락 압력

---

### (2) 이동평균 간 차이

```python
df['ma5_20_spread'] = df['ma5'] - df['ma20']
```

* 양수 → 상승 추세
* 음수 → 하락 추세

---

## 6. 왜 ratio를 사용하는가

* 절대 가격은 시대에 따라 달라짐
* ratio는 상대적인 위치를 나타냄

---

## 7. 핵심 해석

* 가격 > MA → 상승 추세
* 가격 < MA → 하락 추세

---

## 8. 한 줄 요약

Moving Average는
"가격의 노이즈를 제거하고 전체적인 추세를 보여주는 지표"이다.
