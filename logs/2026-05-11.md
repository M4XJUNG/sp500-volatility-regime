# Random Forest Feature Importance

## Feature Importance란?

Feature Importance는 직역하면 “변수 중요도”이다.

즉:

> 머신러닝 모델이 예측할 때  
> 어떤 변수(feature)를 얼마나 중요하게 사용했는가?

를 수치화한 것이다.

---

예를 들어 S&P 500 변동성 레짐 분류에서:

- ATR
- Volatility
- RSI
- MA Ratio
- Volume Ratio

등 다양한 feature를 넣었다고 하자.

그러면 모델은 학습 후:

```text
ATR이 가장 중요함
Volatility가 두 번째로 중요함
RSI는 상대적으로 덜 중요함
````

같은 결과를 만든다.

이것이 Feature Importance이다.

---

# 왜 중요한가?

머신러닝 모델은 종종 “블랙박스(Black Box)”라고 불린다.

즉:

```text
왜 이런 예측을 했는지
인간이 이해하기 어려움
```

이라는 문제가 존재한다.

특히 금융에서는:

* 돈이 걸려 있고
* 리스크 관리가 중요하며
* 설명 가능성(Explainability)이 필요하다.

따라서:

> 모델이 어떤 정보를 기반으로 시장을 판단했는가?

를 이해하는 것이 중요하다.

---

# Decision Tree와 Feature Importance

Random Forest는 여러 개의 Decision Tree를 합친 모델이다.

따라서 먼저 Tree를 이해해야 한다.

---

## Tree의 핵심 구조

트리는 다음처럼 조건문을 반복한다.

```text
if volatility > 20%:
    High Regime
else:
    Low Regime
```

즉:

> 데이터를 특정 기준(threshold)으로 나누면서
> 예측 정확도를 높인다.

---

# Impurity(불순도)

Tree는 데이터를 계속 나누면서:

```text
한 그룹 안의 데이터들이
얼마나 섞여 있는가?
```

를 측정한다.

이것을 Impurity라고 한다.

---

## 예시

### 나쁜 분리

```text
왼쪽 그룹:
High 50%
Low 50%
```

→ 매우 섞여 있음
→ 불순도 높음

---

### 좋은 분리

```text
왼쪽 그룹:
High 95%
Low 5%
```

→ 거의 한 종류
→ 불순도 낮음

---

즉 Tree는:

# “불순도를 가장 많이 줄이는 변수”

를 선택한다.

---

# Random Forest의 Feature Importance

Random Forest는:

```text
여러 개의 Tree
```

를 만든 뒤 평균낸다.

---

각 Tree는:

```text
어떤 feature가
얼마나 impurity를 감소시켰는가
```

를 기록한다.

그리고 전체 Tree에서 평균낸 것이:

# Feature Importance

이다.

---

수식적으로는:

$$\text{Feature Importance(j)}\sum_{t=1}^{T}\text{Impurity Reduction from feature}j$$

이다.

즉:

* 변수 (j)
* 가 Tree 전체에서
* 얼마나 많이 분류 성능 향상에 기여했는가

를 의미한다.

---

# 왜 Random Forest가 Feature Importance를 많이 쓰는가?

## 1. 해석이 쉬움

예를 들어:

| Feature   | Importance |
| --------- | ---------- |
| atr_ratio | 0.24       |
| vol_20d   | 0.19       |
| rsi_14    | 0.04       |

이면:

```text
ATR 기반 변동성 정보가
가장 중요하구나
```

를 직관적으로 이해 가능하다.

---

## 2. 금융에서 중요

금융에서는:

```text
왜 이 예측을 했는가?
```

가 중요하다.

특히:

* 리스크 관리
* 포트폴리오 운용
* 규제
* 투자 설명

등에서는 해석 가능성이 필요하다.

---

## 3. Feature Selection 가능

중요도가 낮은 변수는 제거 가능하다.

예:

```text
importance < 0.01
```

같은 변수 제거.

---

즉:

```text
노이즈 감소
과적합 감소
모델 단순화
```

효과가 있다.

---

# 금융 프로젝트에서의 의미

네 프로젝트에서는:

```python
atr_ratio
vol_20d
vol_ratio_20_60
```

같은 변동성 계열 변수들이 중요하게 나올 가능성이 크다.

왜냐하면:

# 변동성 레짐 자체를 예측하기 때문

이다.

---

반면:

```python
rsi
stochastic
```

같은 단기 모멘텀 변수는 상대적으로 중요도가 낮을 수 있다.

---

즉 Feature Importance는:

# “시장이 실제로 무엇에 반응하는가”

를 데이터 기반으로 보여주는 도구다.

---

# Bootstrap Sampling과 Random Forest

Random Forest는 각 Tree를 만들 때:

```text
Bootstrap Sampling
```

을 수행한다.

즉:

* 원본 데이터에서
* 랜덤하게
* 중복 허용 추출

을 한다.

---

예를 들어:

```text
원본:
[A, B, C, D, E]

샘플:
[A, A, C, E, D]
```

처럼 뽑을 수 있다.

---

# 왜 이렇게 하는가?

Decision Tree 하나는:

# 분산(Variance)이 매우 크다.

즉:

```text
데이터 조금만 바뀌어도
결과가 크게 바뀜
```

---

그래서 Random Forest는:

```text
조금씩 다른 데이터
```

를 Tree마다 보여준다.

그러면:

```text
공통 패턴만 살아남는다.
```

---

즉:

# Variance 감소

가 핵심 목적이다.

---

# Bias-Variance Tradeoff와 연결

머신러닝 핵심은:

$$
Bias^2 + Variance + Noise
$$

의 균형이다.

---

## Tree 하나

* Bias 낮음
* Variance 높음

→ 과적합 위험

---

## Random Forest

* 여러 Tree 평균
* Variance 감소

→ 일반화 성능 향상

---

즉 Random Forest는:

# “복잡한 모델의 분산을 평균으로 줄이는 앙상블”

이다.

---

# 금융 데이터에서 왜 Random Forest가 강한가?

금융 데이터는:

```text
Signal << Noise
```

환경이다.

즉:

* 진짜 패턴은 약하고
* 노이즈는 매우 많다.

---

따라서:

* 너무 단순하면 패턴 못 잡고
* 너무 복잡하면 노이즈 학습한다.

---

Random Forest는:

```text
비선형 패턴 학습 가능
+
과적합 완화
+
해석 가능성 제공
```

이라는 장점이 있다.

그래서 금융 ML에서 매우 자주 사용된다.

---

# Feature Importance 해석 시 주의점

## 1. 인과관계가 아니다

중요도가 높다고:

```text
원인
```

이라는 뜻은 아니다.

단지:

```text
예측에 많이 사용되었다
```

는 의미다.

---

## 2. 다중공선성 문제

예:

```text
vol_20d
vol_60d
atr_ratio
```

는 서로 강하게 연관될 수 있다.

그러면 중요도가 분산될 수 있다.

---

즉:

```text
실제로 중요한 정보인데
importance가 낮게 나오는 경우
```

도 존재한다.

---

# 네 프로젝트 관점에서의 핵심 의미

네 프로젝트에서 Feature Importance는 단순 시각화가 아니다.

이건:

# “시장이 어떤 상태에서 변동성이 커지는가”

를 데이터 기반으로 설명하는 과정이다.

---

예를 들어:

```text
ATR 중요도 ↑
```

이면:

```text
장중 변동폭 확대가
고변동성 레짐의 핵심 신호
```

라는 의미가 된다.

---

즉:

Feature Importance는 단순한 그래프가 아니라:

# 시장 구조를 해석하는 도구

에 가깝다.
