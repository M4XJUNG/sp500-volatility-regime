# 📊 Volatility (Rolling Standard Deviation) 정리

## 1. Volatility 정의

Volatility는 수익률의 표준편차로,
가격이 얼마나 크게 변동하는지를 나타내는 지표이다.

[
\text{Volatility} = \text{Std}(returns)
]

* 수익률 → 방향
* 변동성 → 위험

---

## 2. Log Return 기반 계산

```python
df['log_ret'] = np.log(df['Close'] / df['Close'].shift(1))
```

* 로그 수익률을 사용하여 정상성 확보
* 곱셈 구조 → 덧셈 구조로 변환

---

## 3. Rolling Window 개념

```python
df['vol_20'] = df['log_ret'].rolling(20).std()
```

### ✔️ rolling(20)의 의미

> 현재 시점 기준으로 **과거 20개 데이터만 가져오는 슬라이딩 창**

예시:

```text
t=20 → r1 ~ r20
t=21 → r2 ~ r21
t=22 → r3 ~ r22
```

👉 데이터를 "묶는 역할"만 수행 (계산 X)

---

## 4. 표준편차 계산

각 20일 묶음에 대해:

[
\sigma = \sqrt{\frac{1}{n-1} \sum (r_i - \bar{r})^2}
]

👉 최근 20일 동안 수익률이 얼마나 퍼져있는지 계산

---

## 5. 연율화 (Annualization)

```python
df['vol_20'] = df['vol_20'] * np.sqrt(252)
```

* 252: 연간 거래일 수
* 일간 변동성 → 연간 변동성으로 변환

---

## 6. 왜 20일을 사용하는가

### (1) 거래일 기준

* 1개월 ≈ 20~22 거래일

### (2) 실무 표준

* 옵션 시장
* VaR
* 리스크 관리

👉 월간 변동성 기준으로 널리 사용됨

---

## 7. 변동성 레짐 분류

```python
q33 = vol_20.quantile(0.333)
q67 = vol_20.quantile(0.667)
```

| 구간   | 의미             |
| ---- | -------------- |
| Low  | 하위 33% (안정 시장) |
| Mid  | 중간             |
| High | 상위 33% (불안 시장) |

👉 데이터 분포 기준으로 자동 분할

---

## 8. 핵심 직관

* 변동성 ↑ → 시장 불안정
* 변동성 ↓ → 시장 안정

👉 변동성은 군집(Clustering) 성질이 있어 예측 가능성이 존재

---

## 9. 한 줄 요약

Rolling Volatility는
"최근 N일 동안 시장이 얼마나 크게 흔들렸는지를 측정한 지표"이다.
