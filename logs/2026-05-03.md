### 1. 오늘 본 것

* log return

### 2. 이게 뭔데?

* 수익률을 로그로 변환한 값
* log(P_t / P_{t-1})

### 3. 왜 쓰는거냐?

1. 더 “정상적(stationary)”이다
2. 시간에 따라 더 “일관된 분포”를 가진다
3. 수학적으로 더 다루기 쉽다 (특히 누적)
* 가격은 비정상 (trend 있음)
* 로그 수익률은 정상성 만족 → ML 입력 가능 (ML은 덧셈 구조가 계산하기 편함)
* log return은 “곱셈 구조(복리)”를 “덧셈 구조”로 바꿔서 시간에 따라 일관되게 다룰 수 있게 만드는 도구다.

### 4. 코드에서는?

```python
df['log_ret_1d'] = np.log(df['Close'] / df['Close'].shift(1))
```

* shift(1): 과거 값
* log: 분포 안정화

### 5. 깨달은 점

* 가격 쓰면 모델이 “우상향”만 학습함
